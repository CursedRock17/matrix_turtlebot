# Turtlebot4 Workspace

This workspace contains the entire bringup (both simulation and real life) along with
necessary documents to the get MATRIX Lab Turtlebot4s up to speed.

### Installations
- [ROS 2 Jazzy](https://docs.ros.org/en/jazzy/Installation.html)
- [Nav 2 Jazzy](https://docs.nav2.org/getting_started/index.html#installation)
- [Turtlebot4 Main Package](https://turtlebot.github.io/turtlebot4-user-manual/setup/basic.html)
- [Turtlebot4 Simulation Package - From Source](https://turtlebot.github.io/turtlebot4-user-manual/software/turtlebot4_simulator.html)

### Where to start
- New robot or new laptop: [docs/setup.md](./docs/setup.md), then
  [docs/raspberry_pi_setup.md](./docs/raspberry_pi_setup.md)
- Make a map, then navigate on it: [docs/generate_a_map.md](./docs/generate_a_map.md),
  then [docs/navigate_to_a_goal.md](./docs/navigate_to_a_goal.md)
- Run the examples (start small, build up):
  [turtlebot4_custom_py/README.md](./turtlebot4_custom_py/README.md)
- Something's broken: [docs/troubleshooting.md](./docs/troubleshooting.md)
